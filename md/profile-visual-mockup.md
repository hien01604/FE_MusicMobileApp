## Component States & Interactions

### ProfileHeader States
```
DEFAULT:
  Avatar: Shows image or placeholder with initials
  Edit Button: Outline style, pink border
  
ON PRESS EDIT:
  Button opacity → 0.7
  Navigate to EditProfileScreen
```

### Card States
```
DEFAULT:
  Background: #1a1f3a
  Shadow: Soft shadow (opacity 0.1)
  
ON PRESS:
  Opacity: 0.7
  Navigation/Action triggered

WITH IMAGE ERROR:
  Show placeholder thumbnail
  Continue displaying other data
```

### Button States
```
LOGOUT BUTTON:
  DEFAULT:
    Background: #FF006B
    Text: White
    Shadow: Red glow

  ON PRESS:
    Opacity: 0.8
    Show confirmation dialog

  LOADING:
    Opacity: 0.6
    Show spinner
    Disabled state
    
  ON SUCCESS:
    Navigate to LoginScreen
```

### Menu States
```
MENU ICON (in SongCard):
  INACTIVE: Gray color
  ON PRESS: Show ActionSheet with options
  OPTIONS:
    - Add to Queue
    - Add to Playlist
    - Unlike (if liked)
    - Share
    - Go to Artist
    - Remove
```

## Animations (Optional Enhancements)

```
Scroll → Fade headers at top
```

## Dark Mode Optimization

- Background uses `#0a0e27` (True black for OLED)
- Reduces eye strain in low light
- Saves battery on OLED screens
- Maintains contrast ratio 4.5:1 (WCAG AA)
